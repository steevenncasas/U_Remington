# Ecoturismo CRUD (Perfiles, Personas, Usuarios) - Node.js + Express + MySQL + Bootstrap

Incluye:
- Login (Acceso al sistema) con validaciones
- Dashboard (motivo ecoturismo) + menú Gestión
- CRUD Perfiles (solo Admin)
- CRUD Usuarios (solo Admin)
- CRUD Personas (Admin y Persona)
- Inhabilitar = borrado lógico (campo `estado`)
- Recuperación: genera **contraseña temporal** y la envía por correo al email registrado
